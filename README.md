# Hello Computer - E-Commerce Platform

A premium modern e-commerce platform for computers, custom rigs, laptops, PC components, and gaming peripherals. Built with React 18, TypeScript, Tailwind CSS, and Vite.

## Features
- **Interactive 3D Product Categories**: Single-row showcase with dynamic 3D perspective models for Laptops, Desktops, PC Components, Gaming Peripherals, Audio, and Storage.
- **Custom PC Builder**: Interactive parts configurator with live compatibility, real-time power/price estimation, and custom flagship rig assembly.
- **Deals of the Day**: Live countdown offer tracking with horizontal swiping product slider.
- **Curated Tech Collections**: Category tab filter with product carousels.
- **Authorized Brand Stores**: Official manufacturer warranty tiles for HP, Apple, ASUS, Lenovo, Dell, Acer, and more.
- **Responsive Mobile Experience**: Native mobile bottom navigation bar, slide-out category drawer, sticky utility header, and full touch support.
- **Global Modals & Drawers**: Quick view product modal, shopping cart drawer with promo codes, product comparison modal, and store locator.

## Tech Stack
- **Frontend**: React 18, TypeScript, Tailwind CSS
- **Build Tool**: Vite
- **Icons**: Lucide React

## Getting Started
```bash
cd frontend
npm install
npm run dev
```

## Production Build
```bash
cd frontend
npm run build
```
